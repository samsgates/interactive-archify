# Interactive Architecture Model

IAM is the canonical architecture artifact. It is portable JSON, renderer-independent, and explicitly separates facts, evidence, runtime flows, scenes, stories, narration and review findings.

Confidence values:
- `verified`: direct evidence
- `inferred`: strong deduction
- `hypothetical`: intentional design or simulation
- `unknown`: insufficient evidence

No animation may traverse an edge that is not represented by an IAM relationship.
